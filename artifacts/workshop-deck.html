import chromadb
col = chromadb.PersistentClient("./db").get_or_create_collection("brain")
col.upsert(ids=["n1"], documents=["ประชุมกับอาจารย์ฝน เรื่อง workshop"])

เปิดฝาดูข้างใน · สมการเดียวที่ต้องรู้

Cosine Similarity

cos(A,B) = A·B / (|A|·|B|)

  • A, B = ตัวเลขชุดที่ embedder แปลงจากประโยค 2 อัน
  • "แมวนอนโซฟา" ↔ "ลูกแมวหลับเก้าอี้" = 0.82 (ไม่มีคำซ้ำกันเลย!)
  • จำ "คะแนนติดลบ" เมื่อกี้ได้ไหม? = ทิศตรงข้ามกัน

ระบบจริง

Hybrid = vector + keyword

  • vector เก่งความหมาย — แต่พลาด "PR #2740", คำว่า "ไม่"
  • keyword เก่ง exact term + รหัส
  • รวมด้วยสูตรรวมผล (RRF) — สูตรเดียวกับ ARRA production

ไอเดีย: ให้แต่ละตัวเด่นในเขตของมัน → ครอบทั้ง exact + ความหมาย

ต่อ LLM ให้ตอบจากโน้ตเรา

RAG: ตอบ + อ้างอิง + รู้จักบอก "ไม่รู้"

  • ค้นเจอ → ป้อน context พร้อม source → LLM ตอบ + cite ไฟล์จริง
  • ถามเรื่องนอก vault → "ไม่พบข้อมูล" (ไม่มโน — ซื่อสัตย์ = เชื่อได้)
