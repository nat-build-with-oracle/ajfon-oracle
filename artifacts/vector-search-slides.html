แนวคิด

embedding = พิกัดของความหมาย

คอมเปลี่ยนข้อความเป็นชุดตัวเลข (vector) — ความหมายใกล้กัน พิกัดอยู่ใกล้กัน · ของจริง 1024 มิติ (bge-m3) แต่หลักการ = "ใกล้ = คล้าย"

"งานวิจัยเบาหวาน" → [0.02, 0.91, −0.13, … อีก 1021 ตัว]
คณิตแค่สูตรเดียว

vector search = cosine similarity

function cosine(a, b) {
  let dot=0, na=0, nb=0;
  for (let i=0; i<a.length; i++){ dot+=a[i]*b[i]; na+=a[i]*a[i]; nb+=b[i]*b[i]; }
  return dot / (Math.sqrt(na)*Math.sqrt(nb));   // 0..1 ใกล้ 1 = คล้าย
}

non-tech ไม่ต้องรู้สูตร — พอแค่ "วัดว่า 2 ความหมายใกล้กันแค่ไหน"

Hybrid = FTS + Vector รวมคะแนน

  • FTS จับคำเป๊ะ — ชื่อยา ชื่อคน ตัวเลข

  • รวมกัน = ได้ทั้ง "แม่นคำ" และ "เข้าใจความหมาย"
