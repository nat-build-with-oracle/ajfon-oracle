พูดตรงๆ · Agentic AI ไม่ใช่เวทมนตร์

รู้ทันข้อจำกัด = ใช้เป็น

  • ~70% ของงาน "หลาย agent" จริงๆ agent เดียวถูก/เร็ว/เชื่อถือกว่า
  • ต่อกันหลายขั้นความผิดพลาดสะสม — 85%/ขั้น × 10 ขั้น = สำเร็จแค่ 19.7%
  • ตรวจ citation ทุกอันเสมอ — AI สร้างชื่อ paper ปลอมได้เนียนมาก

กฎง่ายๆ: มันคือ ผู้ช่วย junior ที่ต้องคุม ไม่ใช่ผู้เชี่ยวชาญอิสระ

ทำไม ARRA Oracle ยืนได้ (มีหลักฐาน)

ไฟล์ธรรมดา + อยู่ในเครื่อง = เลือกที่ถูก

  • ไฟล์ชนะ vector database เมื่อ < 10,000 docs — งานวิจัยคนเดียวอยู่ในช่วงนี้พอดี
  • Letta filesystem 74% ชนะ mem0-graph 68.5% (LoCoMo) — *ตัวเลข vendor ขัดกัน อ้างอย่างระวัง
  • 60,000+ โปรเจกต์ ใช้ markdown เป็นความจำ ไม่มี infra เลย (Claude Code, Cursor)
  • ข้อมูลอยู่ในเครื่องคุณ 100% · cite กลับโน้ตที่คุณ verify เอง
