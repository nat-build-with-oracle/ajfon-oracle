## บทพูดต่อสไลด์

**สไลด์ 2 (ปัญหา):**
> "ใครเคยจำได้ว่าเคยอ่านอะไรไว้ แต่พิมพ์คำค้นเท่าไหร่ก็หาไม่เจอ? ... นั่นแหละปัญหาของ Ctrl+F — มันหาเฉพาะคำที่เราสะกดตรงเป๊ะ"

**สไลด์ 3 (🔴 LIVE เดโมหลัก — จุดตาย):**
> "ดูนี่นะครับ ผมจะค้นคำเดียวกัน 2 วิธี"
- รันจริง: `rg "clipboard"` (หรือคำที่ตกลงไว้) → เจอเฉพาะไฟล์ที่มีคำ
- รันจริง: `muninn_search` ด้วยคำที่**ไม่มีในเอกสารเลย** เช่น query "วางแล้วเพี้ยน" → เจอ doc เรื่อง tmux mouse paste
> "เห็นไหมครับ — คำค้นกับผลลัพธ์**ไม่มีคำตรงกันสักคำ** แต่มันเข้าใจว่าความหมายใกล้กัน"
- แบ็คอัพ (ถ้า backend ไม่พร้อม): เปิด module → แตะปุ่มคำค้นในแผนที่ความหมาย

**สไลด์ 4–5 (concept):**
> "คอมเปลี่ยนข้อความเป็นตัวเลข — เหมือนให้พิกัดกับความหมาย ประโยคความหมายใกล้กันอยู่ใกล้กันในแผนที่ · ของจริงมี 1024 มิติ แต่ไม่ต้องกลัว หลักการแค่ 'ใกล้ = คล้าย'"
> (สไลด์ code) "คณิตมีสูตรเดียวจริงๆ ชื่อ cosine — ไม่ต้องจำ พอรู้ว่ามันวัดว่า 2 ความหมายใกล้กันแค่ไหน"

**สไลด์ 6–7 (เทียบ + hybrid):**
> "FTS จับคำเป๊ะ — ดีเวลาจำชื่อยา ชื่อคน ตัวเลข · Vector จับความหมาย — ดีเวลาจำได้แค่ไอเดียลางๆ · **ของจริงใช้ทั้งคู่**"

**สไลด์ 8 (honest — สำคัญ สร้างความน่าเชื่อถือ):**
> "พูดตรงๆ นะครับ ตอนนี้ระบบเราเปิด FTS ก่อน ส่วน vector กำลังย้ายขึ้น cloud — เพราะรันในเครื่องมันกินทรัพยากร · แต่โค้ดพร้อมแล้ว มี benchmark จริง ไม่ใช่ของขายฝัน"

**สไลด์ 9 (ปิด):**
> "ถ้าจะจำอย่างเดียว: AI ที่ค้นความรู้ของคุณเจอ 'ด้วยความหมาย' + อ้างกลับไฟล์จริง = ไม่มั่ว"

## Q&A ที่มักโดนถาม (เตรียมคำตอบ)
- **"ต่างจาก ChatGPT ยังไง?"** → ChatGPT ตอบจากความรู้ทั่วไป/เว็บ · อันนี้ตอบจาก**โน้ตของคุณเอง** + cite กลับไฟล์จริง
- **"ข้อมูลปลอดภัยไหม?"** → อยู่ในเครื่องคุณ 100% (markdown) ไม่ขึ้น cloud
- **"vector แม่นกว่า FTS เสมอไหม?"** → ไม่ · บางทีจับความหมายผิด → เลยใช้ hybrid
- **"ต้องเขียนโค้ดเป็นไหม?"** → ไม่ · วันนี้ดูเดโม · อยากลองเองมี guide ให้
