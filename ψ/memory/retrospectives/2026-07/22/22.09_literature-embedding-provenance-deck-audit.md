## Lessons Learned

- **A CSS media-query override that "does nothing" is a source-order bug before it's a caching bug.** When a `@media(...)` rule and an unconditional base rule share a selector and specificity, the later-in-source rule wins the tie regardless of which one is wrapped in a media query. Check position relative to the base rule first — it's a five-second grep, versus a multi-step caching investigation.
- **When a visual fix "doesn't seem to work," measure before re-guessing.** A tiny injected debug overlay reporting `getBoundingClientRect`/`getComputedStyle` values turns "looks the same, maybe it's cached?" into an exact number in one screenshot. Reach for this on the *first* unexpected non-result, not the third.
- **"Show me a picture" of an investigation likely means a real image exists to find, not a report to author.** When the ask is ambiguous between "synthesize a visual summary" and "locate the actual artifact," default to searching before building — building is expensive to undo and the search itself usually resolves the ambiguity.
