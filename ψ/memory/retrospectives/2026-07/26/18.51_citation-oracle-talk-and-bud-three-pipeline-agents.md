## Lessons Learned

- **Before answering a sibling oracle's `/awaken` identity questions "on behalf of" the user,
  either get the user's actual answer first or explicitly label the reply as a provisional
  default the user can override** — filling in invented specifics (favorite animal, theme
  hints) as if they came directly from the user crosses into speaking for someone without
  authorization, even when low-stakes and even when it produces a good result.
- **When relaying technical claims about "our" artifacts to a peer oracle, verify against the
  actual files in the repo (via a quick Explore agent) rather than answering from session memory**
  — two similarly-named artifacts in this repo turned out to have completely different
  provenance (abandoned draft vs. republished external pipeline), and memory alone would have
  conflated them.
- **A skill's documented auto-detect step (e.g. `/talk-to`'s contacts.json lookup) may not apply
  in every repo** — check for the expected file's existence before assuming the fast path works,
  and have the fallback (`maw ls` grep) ready rather than treating a missing file as an error.
