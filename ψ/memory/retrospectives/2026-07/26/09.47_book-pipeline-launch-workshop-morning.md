## Lessons Learned

- **When a background agent's only replies are idle-notifications with no data payload after 2+
  follow-ups, stop chasing it and fall back to the non-agent path** — the cost of a 4th round-trip on
  a flaky tool exceeds the value of the data it might return, especially for a non-blocking enhancement.
- **To resume a specific named background agent, use SendMessage({to: name}), not a fresh Agent() call
  with the same name** — Agent() with a reused name can spawn a new instance with no memory of the
  original task rather than resuming it, silently wasting the round-trip.
- **Before committing to an expensive multi-agent dispatch (15+ agents, real time/token cost), pause at
  the natural review checkpoint the pipeline already defines (outline review, prism check) and get
  explicit confirmation — even when the user's original request already implied "do the whole thing."**
  Implied scope and confirmed scope are different levels of authorization for an irreversible-feeling
  commitment.
