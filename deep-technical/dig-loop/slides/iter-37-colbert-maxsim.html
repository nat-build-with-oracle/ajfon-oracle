ColBERT MaxSim — เก็บเวกเตอร์ต่อ token ไม่บีบเป็น 1 ตัว แต่ละ query token หา doc token ที่ใกล้สุด ไม่สนใจว่ารอบข้างมีอะไรปนอยู่

score(q,d) = Σᵢ maxⱼ cos(qᵢ, dⱼ) — "late interaction": encode แยก, match ตอน score

doc ที่ครอบคลุมจริง แต่ปนขยะเยอะ

doc มี 6 token: 1 เบาหวาน, 1 ออกกำลังกาย, 4 filler

dense (pool ทั้งหมด) = 0.333 ← เจือจางจาก filler
MaxSim (per-token) = 1.997 ← เจอ 2 token จริง ไม่แคร์ filler

ต้นทุนที่แลกมา

dense: 1 vector/doc · O(1) cosine
ColBERT: 6 vectors/doc · MaxSim = 12 comparisons
  (n=2 query token × m=6 doc token)

แม่นกว่า dense แต่ storage+compute แพงกว่า n×m เท่า
ทั้งสองวิธี reject doc ที่ไม่เกี่ยวถูกต้อง — MaxSim ชนะเฉพาะเคส "ครอบคลุมจริงแต่ปนขยะ" bi-encoder เร็ว ↔ cross-encoder แม่น ↔ ColBERT ตรงกลาง
