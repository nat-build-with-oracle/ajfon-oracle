พิสูจน์: Normalize แล้ว Dot Product = Cosine ทำไม LanceDB/FAISS normalize เวกเตอร์ก่อนเก็บ แล้ว search ด้วย dot ตรงๆ ไม่หาร norm ทุก query

อ้าง (Ch1 §1.6): ถ้า ‖a‖ = ‖b‖ = 1 แล้ว a · b = cos θ
พิสูจน์: จากนิยาม a · b = ‖a‖‖b‖cos θ  →  แทน ‖a‖=‖b‖=1
    a · b = 1 · 1 · cos θ = cos θ  ∎

1 · ก่อน normalize

a = (3, 4)  →  ‖a‖ = 5
b = (−2, 1)  →  ‖b‖ ≈ 2.236

ความยาวไม่เท่ากัน → dot(a,b) ดิบ
ไม่เท่ากับ cosine

2 · หลัง normalize

â = (0.6, 0.8)  ‖â‖ = 1
b̂ = (−0.894, 0.447)  ‖b̂‖ = 1

â · b̂ = 0.6·(−0.894) + 0.8·0.447
   = −0.1789 = cos(a,b) ตรงเป๊ะ
index-time: normalize ครั้งเดียว · query-time: dot เฉยๆ — เร็วกว่าหาร norm ทุกครั้ง ‖a‖=‖b‖=1 ⟹ a·b = cosθ
