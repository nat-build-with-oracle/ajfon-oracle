Chunking — 1 Chunk ควร = 1 ความคิด เอกสารหลายหัวข้อบีบเป็น 1 เวกเตอร์ = เจือจาง — หั่นให้ถูกวิธีคือ recall ที่ดีขึ้น

1 · dilution วัดได้จริง

query: "ทำไม embedder อ่านไทยไม่ออก"
cos(query, doc 3 หัวข้อรวม) = 0.624
cos(query, chunk เฉพาะหัวข้อ) = 0.658
เฉพาะเจาะจงกว่า = คมกว่าเสมอ

2 · fixed-size ตัดกลางประโยค

70 chars ไม่มี overlap → ประโยคขาด ✗
70 chars + overlap 30 → ประโยคครบ ✓
recursive (แบ่งตาม \n\n) → 3 chunk ตรงย่อหน้าเป๊ะ

3 · parent-child: คมและครบพร้อมกัน

ค้นด้วย child (ประโยคเดียว) cos = 0.735
parent (ทั้งย่อหน้า) cos = 0.658
child คมกว่า แต่ parent (132 ตัวอักษร) ให้บริบทมากกว่า child (64)
