Q: "อยากได้กาแฟไม่หวาน"

bi-encoder: sweet=1.000 unsweet=0.930 → ผิด!
cross-encoder: sweet=0.500 unsweet=1.430 → ถูก

bi-encoder แยกเข้ารหัสก่อนเจอ query
→ "ไม่" ถูกเฉลี่ยจางหาย เหมือน book/07: cos(มีน้ำตาล,ไม่มีน้ำตาล) สูง

2 ชั้น: recall ถูก + precision แม่น

stage1 bi-encoder: score ครบ 200 doc (ถูก+เร็ว)
stage2 cross-encoder: rerank แค่ 50 doc (แม่น+แพง)

rerank ทั้ง 35k doc = เป็นไปไม่ได้
rerank แค่ 50 = ไหว
เงื่อนไขสำคัญ: doc ที่ถูกต้องต้องติด top-50 ของ stage1 ก่อน — ถ้า stage1 พลาด stage2 ช่วยไม่ได้ (recall@50 ต้องสูง)
